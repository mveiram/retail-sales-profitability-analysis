# Retail Sales & Profitability Analysis

## Project Overview

This portfolio project analyzes retail sales and profitability data to identify the main drivers of business performance and opportunities for improvement.

The project follows an end-to-end data analytics workflow:

**Python → SQL Server → Power BI → Business Insights**

## Business Question

> What factors are driving sales and profitability, and where should the company focus its efforts?

## Objectives

- Understand sales and profit performance over time.
- Analyze product, category, segment, and regional performance.
- Evaluate the relationship between discounts and profitability.
- Identify loss-making products and business areas for further investigation.
- Build an executive Power BI dashboard to communicate findings.

## Tools

- Python (Pandas, Matplotlib)
- SQL Server
- Power BI
- GitHub
